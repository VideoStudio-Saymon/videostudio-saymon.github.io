Política de Privacidade — VideoStudio

Última atualização: 11 de novembro de 2026

  1. Quem usa: o VideoStudio é uma ferramenta de uso pessoal do proprietário dos canais. Não há outros usuários.
  2. Dados acessados: com autorização do proprietário, o app usa a API do YouTube para enviar vídeos, definir títulos, descrições, miniaturas e agendamento, e ler estatísticas dos próprios canais (escopos youtube.upload e youtube.readonly). Também pode usar a API de publicação do TikTok para enviar vídeos aos próprios perfis do proprietário.
  3. Armazenamento: os tokens de acesso ficam salvos apenas no computador do proprietário. Nenhum dado é enviado a servidores do VideoStudio (não existem), nem vendido ou compartilhado com terceiros.
  4. Revogação: o acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions e nas configurações de apps autorizados do TikTok.
  5. Uso dos dados do Google: o uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
  6. Contato: github.com/VideoStudio-Saymon
